# Security

Chan Sampler reads audio files, FL Studio presets and saved projects, so a
crafted file that crashes it or does worse is a security bug.

Please report one privately with GitHub's **Report a vulnerability** button
(Security tab > Advisories), not in a public issue. Include the file or steps
that trigger it and the Chan Sampler version, host and OS.

Fixes go into the next release; only the latest release is supported.

Release downloads are unsigned. Check them against the `SHA256SUMS.txt` that
comes with each [release](https://github.com/MaymiPR/Chan-Sampler/releases).
